# LTX Library Enhancer For Korean User

**Jasna-LTX (`ltxlib.dpdns.org`)** 이용자를 위한 한국어 통합 확장 유저스크립트입니다.  
배우 이름 한글화, 한글·초성·영문 배우 자동완성 검색, 다중 명의(대표 이름) 통합 검색, 데이터 내보내기, 외부 검색 사이트(`extLink`) 커스텀 기능을 제공합니다.

---

## 1. 설치 방법 (원클릭 설치)

1. 브라우저에 **[Tampermonkey](https://www.tampermonkey.net/)** 확장 프로그램을 설치합니다.
2. 아래 원클릭 설치 링크를 클릭하면 Tampermonkey 설치 화면이 자동으로 열립니다.
   * 👉 **[LTX Library Enhancer For Korean 설치하기](https://stag-lab.github.io/library-enhancer/LTX-Library-Enhancer-For-Korean.user.js)**
   * 만약 설치 창 대신 소스 코드 텍스트 화면이 열린다면:
     * 해당 페이지의 주소창 URL을 복사합니다.
     * **Tampermonkey 대시보드 → 유틸리티(Utilities) → URL에서 가져오기(Import from URL)** 칸에 주소를 붙여넣고 **설치**를 클릭합니다.
3. 설치 창에서 **설치(Install)** 버튼을 누른 뒤 `https://ltxlib.dpdns.org/` 페이지를 새로고침합니다.
4. 최초 설치 후 **자동 스크롤 기능** 을 실행해서 전체 데이터를 한번 불러와야 모든 기능을 제대로 이용할 수 있습니다.
> **업데이트 방법:** Tampermonkey 대시보드에서 본 스크립트의 **최근 업데이트 일시** 을 클릭하면 GitHub에 올라온 최신 버전으로 자동 업데이트됩니다.
---

## 2. 주요 기능 요약

### 🔍 한글 · 영문 · 초성 배우 검색 (`Ctrl + K` / `한/EN`)
* 검색창 내부의 **`한/EN`** 버튼 또는 단축키 **`Ctrl + K`**(`Cmd + K`)로 배우 검색 모달을 즉시 열 수 있습니다.
* **한글명, 초성(예: `ㅅㅋㅁㅊ`), 영문명, 일본어 원문명, 대표 이름**을 모두 지원하며, `nav.actors` 기반 배우별 보유 작품 수(`N건`)가 함께 표시됩니다.
* **입력 모드 전환 지원:**
  * **대표 이름 입력:** 동일 인물의 여러 활동명(구명의·신명의)을 묶은 대표 일본이름으로 검색어를 입력합니다.
  * **개별 이름 입력:** 선택한 개별 일본이름을 검색창에 입력합니다.

### 🧩 다중 명의(대표 이름) 통합 카드 검색
* **대표 이름 입력** 모드로 검색 시, 동일 대표 이름으로 묶인 다른 명의의 작품까지 모두 검색 결과에 보여집니다.

### 👤 배우 캐시 및 스킵·무시 3탭 통합 관리
* 페이지 내 일본어 배우명을 자동으로 조회하여 **한글명(영문명)**으로 변환하고 로컬 캐시에 저장합니다.
* 상단 **`데이터로드` → `배우 캐시 / 스킵 관리`** 메뉴에서 다음 3개 탭을 관리할 수 있습니다:
  1. **저장된 배우 캐시:** 개별/일괄 대표 이름 지정, 이름 수정, 재조회, CSV 일괄 가져오기
  2. **no-data 스킵 목록:** AVDBS 미등록 배우 수동 등록, 클립보드 복사 및 무시 목록 이동
  3. **무시된 배우:** 작품 수 순 정렬 및 다중 선택 일괄 무시 해제

### 💾 JSON/CSV 내보내기
* 현재까지 누적된 데이터를 JSON 및 CSV파일로 다운로드 할 수 있습니다.
* **데이터 점검 및 선택 백업/복원/초기화:**
  * 누락 항목만 필터링해 정리할 수 있습니다.
  * 배우 캐시, 스킵/무시 목록, 외부 사이트 설정을 체크박스로 골라 백업·복원·초기화할 수 있습니다.

### 🔗 카드별 외부 검색 사이트 (`extLink`) 커스텀
* 외부 사이트로 해당 품번을 즉시 검색할 수 있는 **`extLink`** 메뉴가 표시됩니다.

## 3. 단축키 및 콘솔 디버깅 (`LtxDebug`)

### 단축키 안내
| 단축키 | 동작 설명 |
| :--- | :--- |
| **`Ctrl + K`** (Mac: `Cmd + K`) | 한글 / 영문 / 초성 배우 자동완성 검색 팝업 열기 |
| **`Esc`** | 열려 있는 모든 관리 모달 닫기 |
| **`Alt + 배우 이름 클릭`** | 해당 배우의 스킵·무시 상태를 해제하고 AVDBS 즉시 재조회 |

### 개발자 도구 콘솔 디버깅 (`LtxDebug`)
브라우저에서 `F12`를 눌러 **Console** 탭을 연 뒤 컨텍스트 전환 없이 아래 명령어를 바로 실행할 수 있습니다.

```javascript
// 1. 전체 모듈 로드 상태, 누적 데이터 건수, DOM 마운트 현황 표로 출력
LtxDebug.status();

// 2. 캐시된 배우 정보 검색 (한글명, 일본어명, 영문명, 대표 이름)
LtxDebug.findActor('검색어');

// 3. IndexedDB에 누적된 특정 품번의 원본 데이터 객체 조회
LtxDebug.findItem('ABC-123');

// 4. 현재 화면의 카드 병합 및 상단 카운터 수동 강제 갱신
LtxDebug.refresh();
